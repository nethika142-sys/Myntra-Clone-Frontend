# Myntra Clone

## Project Overview
This is a frontend clone of the Myntra e-commerce website. The project focuses on replicating the home page, product listing, navigation bar, and footer, using only HTML and CSS. 

## Features
- Responsive navigation bar with dropdown menus
- Product cards displaying images, name, and price
- Fully responsive layout for mobile and desktop
- Footer and social media icons

## Tech Stack
- HTML5
- CSS3
- VS Code Live Server (for local preview)

## Purpose
This project helped me practice creating a real-world e-commerce frontend, focusing on layout design, responsive design, and CSS styling.

## How to Run
1. Open `index.html` in a browser
2. Or use **Live Server** in VS Code for live preview
